# ⚡ Hero Analysis - Gerenciador de Missões

> _“Disciplina hoje, o herói de amanhã.”_

Um gerenciador de tarefas (_to-do list_) moderno com temática inspirada em painéis de controle futuristas (HUD) e cultura pop, desenvolvido com foco em performance, responsividade e uma experiência de usuário imersiva.

## 🌐 Acesso Online

Você pode acessar a aplicação rodando ao vivo pelo GitHub Pages clicando no link abaixo:

- 👉 [Gerenciador de Tarefas](https://fco-gabriel-silva.github.io/Gerenciador-de-Tarefas/)

## 🚀 Funcionalidades

- **Gerenciamento Completo de Missões:** Adicione, edite, conclua e exclua tarefas do seu dia a dia.
- **Sistema de Ranks:** Classifique suas missões por níveis de importância com assets visuais personalizados (Rank A, B, C).
- **Barra de Progresso Dinâmica:** Acompanhe a porcentagem de conclusão das missões em tempo real com animações fluidas de contagem.
- **Persistência de Dados:** Suas missões ficam salvas no navegador (`localStorage`) para garantir que você não perca seu progresso.
- **Totalmente Responsivo:** Layout otimizado e fluido para funcionar perfeitamente em computadores, notebooks, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web modernas sem o uso de frameworks pesados, garantindo código limpo e aprendizado profundo dos fundamentos:

- **HTML5** (Semântica e validação nativa)
- **CSS3** (Flexbox, Variáveis CSS, Media Queries e Animações)
- **JavaScript (ES6+)** (Orientação a Objetos, Manipulação do DOM e LocalStorage)
- **Git & GitHub** (Controle de versão)

## 📱 Responsividade e Adaptabilidade

O projeto conta com uma estrutura planejada para se adaptar a diferentes resoluções de tela, garantindo uma interface limpa, compacta e sem quebras de layout em:

- Smartphones
